Use it

<main class="container">
  <section class="section stack gap-5">
    <h2>Trips</h2>
    <div class="grid">…cards…</div>
  </section>
  <hr class="divider">
  <section class="section stack">…</section>
</main>

Use when

  • A plain-CSS site needs a page width, a column, a row or a grid of cards.
  • Spacing between siblings should come from one gap on the parent.
  • Sections should follow the tier's rhythm, with a .divider where a hairline helps.

Don't use when

  • The site uses Tailwind. Tailwind sites keep Tailwind's own layout utilities. These are for plain-CSS sites.
  • You want to space one child differently. Change the parent's gap, don't add margins to children.
  • The content is a table of data. Use the table component.

Rules

  • Space between children is always the parent's gap. Don't add margins to children.
  • .grid never overflows: a column is at least --grid-min or the whole row, whichever is smaller. Set --grid-min on the element to change it.
  • The gap modifiers beat any component's own gap, so .card.gap-2 tightens a card.

Accessibility

  • These classes only place things. Use the right elements underneath: <main>, <section> with a heading, <hr> for a divider.
  • Layout changes the visual order only by wrapping, never by reordering, so reading and tab order match what people see.
  • The container keeps text to a readable measure, and the grid reflows to one column on a phone with no sideways scroll.
  • In forced colours the divider keeps a visible line.
