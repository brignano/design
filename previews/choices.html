Use it

<fieldset class="choice-group">
  <legend>Notify me</legend>
  <label class="choice"><input type="checkbox" name="notify" value="email"><span>By email</span></label>
</fieldset>

<!-- with a hint: a div row, so the hint isn't part of the name -->
<div class="choice">
  <input type="radio" id="fast" name="ship" aria-describedby="fast-hint">
  <label for="fast">Express</label>
  <p class="choice-hint" id="fast-hint">Two working days.</p>
</div>

<label class="choice"><input type="checkbox" role="switch" class="switch"><span>Holiday decorations</span></label>

<fieldset class="choice-group">
  <legend>View</legend>
  <div class="segmented">
    <label><input type="radio" name="view" value="day" checked>Day</label>
    <label><input type="radio" name="view" value="week">Week</label>
  </div>
</fieldset>

Which one

  • Checkbox: any number of options, or one yes/no that is sent with a form.
  • Radio: exactly one of a few options, all visible, with room for a hint each.
  • Switch: a setting that takes effect the moment it flips. Never inside a form with a submit button: use a checkbox there.
  • Segmented: one of two to five short options that change a view or a unit. Longer lists are radios or a select.

States

  • Checkboxes and radios are native, coloured by accent-color: var(--i) from tokens.css.
  • The switch knob moves right when on, so the state reads without colour.
  • Focus is the 2px --i-ink ring; on a segment it rings the label.
  • disabled goes neutral (--i-disabled-*), and the row's text dims with it.

Accessibility

  • Group related choices in a <fieldset> with a <legend>; the legend names the group.
  • The switch is a checkbox with role="switch": screen readers say "on" and "off". Announce what changed if the effect isn't visible.
  • Segments are real radios: Tab reaches the group, arrow keys move the choice, and nothing needs a script.
  • Rows reach 44px on touch, so the whole label is the target.
