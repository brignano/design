Filter chip

A toggle for a filterable list. Press one to turn a filter on, press it again to turn it off, and any number can be on at once. The state comes from aria-pressed, never a class.

Use it

<div class="cluster gap-2" role="group" aria-label="Stage">
  <button type="button" class="chip" aria-pressed="true">Lead</button>
  <button type="button" class="chip" aria-pressed="false">Quoted</button>
  <button type="button" class="chip" aria-pressed="false">Booked</button>
</div>

Your script flips aria-pressed on click and filters the list. The CSS draws the rest.

Use when

  • A list can be narrowed by several values at once: stages, classes, grades.
  • There are few enough values to show them all, and the filter applies the moment a chip is pressed.

Don't use when

  • Only one value can be chosen. Use a segmented control.
  • You are showing a filter that is already applied and can be removed. Use a tag.
  • The choice is sent with a form. Use checkboxes.
  • It is a setting, not a filter. Use a switch.
  • It only shows a status. Use a pill.

Layout and labels

Chips wrap onto more rows on a narrow screen; they never scroll sideways, so every filter stays in view. The label is one or two words in sentence case, with no emoji and no count that changes the chip's width as you filter. With nothing pressed, show the whole list.

Accessibility

  • A real button. <button type="button"> with aria-pressed="true" or "false", so Space and Enter toggle it and a screen reader says "pressed" or "not pressed".
  • Name the group. Wrap the chips in role="group" with an aria-label or aria-labelledby that says what they filter.
  • Say what changed. Put the result count in a role="status" element so the new count is announced after each press.
  • The on state is a fill and a contrast change, not hue alone. In forced colours it uses the system highlight.
  • 32px tall with a pointer, 44px on touch. The focus ring is 2px, offset from the chip.
