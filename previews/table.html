Use it

<div class="table-wrap">
  <table class="table">
    <caption>Containers on the homelab</caption>
    <thead><tr>
      <th scope="col">Name</th>
      <th scope="col" class="num" aria-sort="descending">
        <button type="button">CPU %</button>
      </th>
    </tr></thead>
    <tbody><tr><td>ollama</td><td class="num">41.3</td></tr></tbody>
  </table>
</div>

Use when

  • People compare values across rows: prices, sizes, counts, dates.
  • The columns are the same for every row.

Don't use when

  • Each item has a different shape. Use cards or a key-value list.
  • It's for layout. Tables are for data only.

Accessibility

  • Every header cell is a <th scope="col">; a row header is <th scope="row">.
  • Give the table a <caption>, or aria-label when a visible heading already names it.
  • Sortable: aria-sort goes on the <th> (ascending, descending, or none), and the control inside is a real <button>. Your script sorts the rows and updates aria-sort; the arrows follow it.
  • Only one column has ascending or descending at a time.
