Use it

<button type="submit" class="btn btn-primary">Save</button>
<a class="btn btn-secondary" href="/back">Cancel</a>
<button type="button" class="btn btn-ghost btn-icon" aria-label="Close"><svg …></svg></button>

<!-- while saving: your script sets it and ignores clicks -->
<button class="btn btn-primary" aria-busy="true">Save</button>

<p>Read the <a class="link" href="/terms">terms</a>.</p>

Use when

  • Someone acts: save, send, delete, open a dialog. Use <button>.
  • A link should look like an action, such as "Cancel" next to "Save". Put .btn on the <a href>.
  • A link sits inside running text: .link.
  • For the words, follow Buttons and links in the content guidelines.

Don't use when

  • Navigation inside running text: use .link, not a button.
  • A choice between options: the segmented control, not a row of buttons.
  • Two primaries side by side: make one secondary.

Variants

  • Primary: the one action the view exists for. One per view.
  • Secondary: everything else, and the look of a bare .btn.
  • Ghost: low-weight actions in toolbars and next to a primary.
  • Danger: deletes or loses something. The only fill that isn't cobalt; confirm before it acts.

Sizes and shapes

  • .btn-sm 32px, default 40px, .btn-lg 48px; all reach 44px on touch.
  • .btn-icon is square and needs an aria-label.
  • .btn-block fills its row, for phone forms and dialogs.
  • One radius on every button: --radius-control (8px), the same corner as an input.
  • A button settles by 2% while it is pressed, unless it is disabled or busy. Not under prefers-reduced-motion.

States

  • Hover and pressed swap the fill: --i-hover, --i-pressed on primary; neutral surfaces on secondary.
  • Focus is the 2px --i-ink ring, 2px out. Never removed.
  • disabled on a button, aria-disabled="true" on a link or a button that must stay focusable (so its tooltip can explain why). Both get the neutral disabled fill; your script ignores clicks on aria-disabled.
  • aria-busy="true" hides the label behind a spinner without changing the width.

Accessibility

  • Use <button> for actions and <a href> for navigation; the class is the same.
  • Every label passes 4.5:1 in both themes, in every state but disabled, which WCAG exempts because the control is really inactive.
  • Targets reach 44px on touch. The busy spinner slows under reduced motion; announce the result of the action yourself.
