Use it

<div class="field">
  <label for="phone">Phone <span class="field-optional">(optional)</span></label>
  <input id="phone" type="tel" aria-invalid="true"
         aria-describedby="phone-hint phone-error">
  <p class="field-hint" id="phone-hint">Only for delivery questions.</p>
  <p class="field-error" id="phone-error"><svg aria-hidden="true" …></svg>Enter the whole number.</p>
</div>

<div class="field">
  <label for="price">Price (USD)</label>
  <div class="field-affix"><span>$</span><input id="price" inputmode="decimal"></div>
</div>

Parts

  • .field stacks the label, the control, then .field-hint and .field-error.
  • Text-like <input>, <textarea> and a native <select> are styled inside it. Checkboxes, radios and switches are a separate component.
  • .field-optional holds the words "(optional)". Required fields carry no star.
  • .field-affix wraps the control with a unit or an icon, before or after it.

States

  • Rest is a --line-control edge on --card; hover darkens it to --ink-soft.
  • Focus is the 2px --i-ink ring, 2px out; on an affix it rings the whole wrapper.
  • aria-invalid="true" turns the edge to --danger. Show .field-error with it; hide it with hidden.
  • disabled drops the edge and fills with --surface-hover. The value stays readable at 4.5:1.

Rules

  • The label sits above the control. A placeholder is an example, never the label.
  • Mark the optional fields, not the required ones.
  • Name the unit in the label too ("Price (USD)"): screen readers don't read the affix as part of the field.
  • When to validate (on blur, on submit) is your script's call.

When not to

  • Floating labels: not part of the system.
  • A custom dropdown: style the native <select> instead.
  • Dates: native date inputs wait for wave 3.

Accessibility

  • Every control has a <label for>. Point aria-describedby at the hint and the error, so screen readers read both after the label.
  • The error says what to do, and the danger icon backs up the colour, so the error doesn't rely on red alone.
  • Controls are 40px tall, and 44px on touch. Text inputs use the base size, so phones don't zoom in.
  • Under forced colours the select gets its native arrow back.
