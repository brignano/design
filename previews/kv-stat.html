Use it

<dl class="kv">
  <dt>Booked</dt><dd>7 Nov 2026</dd>
</dl>

<div class="stat-grid">
  <div class="stat">
    <span class="stat-label">Visitors this week</span>
    <span class="stat-value">1,284</span>
    <span class="stat-delta" data-dir="up" data-tone="good">Up 12% from last week</span>
  </div>
</div>

Use when

  • Key-value: one item's details, like a receipt, a booking or a settings summary.
  • Stat: a few headline numbers someone checks at a glance.

Don't use when

  • Several items share the same fields. Use a table.
  • The number needs a trend over time. Use a chart.
  • Colouring a delta whose direction isn't good or bad for the reader. Leave out data-tone.

Accessibility

  • Use a real <dl> so screen readers announce terms and values as pairs.
  • The delta's words carry the direction ("Up 12%"); the arrow is hidden from assistive tech, and colour is never the only signal.
  • Put the label before the value in source order, as shown, so the number is read with its meaning.
