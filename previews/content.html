Sizes and classes

  • Avatar: .avatar-sm 24px, .avatar 40px, .avatar-lg 64px.
  • Code tokens: .tok-keyword, .tok-string, .tok-comment; a highlighted line is .line-highlight. Everything else stays --code-ink.
  • Colours are tokens (--code-*) so a highlighter theme can map to them.

Don't

  • Colour more token types. Keywords in cobalt, comments in italics: that's enough to scan.
  • Use the blockquote for a callout or a warning. Use a message.
  • Put an avatar where the name isn't nearby or in its label.

Behaviour your script owns

  • The copy button copies the code's text, then says "Copied" for about two seconds. Announce it with an aria-live="polite" region or by changing the button's text.
  • Highlighting is up to your build (shiki, Prism or hand-written spans), as long as it emits the token classes or uses the --code-* colours.

Accessibility

  • The code block scrolls sideways instead of wrapping, so give its <pre> tabindex="0" and an aria-label: keyboard users can then scroll it.
  • An initials avatar is role="img" with the full name as its aria-label; a photo needs real alt, or alt="" when the name is right beside it.
  • Every figure image needs alt; the caption doesn't replace it.
