Use

<a class="skip-link" href="#main">Skip to content</a>
<header class="site-header">
  <div class="site-header-inner container container-wide">
    <a class="site-brand" href="/">…logo… Name</a>
    <nav class="site-nav" id="site-menu" popover aria-label="Main">
      <button type="button" class="btn btn-ghost btn-icon site-menu-close"
              popovertarget="site-menu" popovertargetaction="hide"
              aria-label="Close menu" autofocus>…</button>
      <ul><li><a href="/" aria-current="page">Home</a></li>…</ul>
    </nav>
    <div class="site-actions">…</div>
    <button type="button" class="btn btn-ghost btn-icon site-menu-button"
            popovertarget="site-menu" aria-label="Menu">…</button>
  </div>
</header>
<main id="main">…</main>
<footer class="site-footer">…</footer>
  • The phone menu needs no script. The popover attribute gives you Esc and click-outside to close. The autofocus close button takes focus when the menu opens, and focus goes back to the menu button when it closes.
  • The collapse follows the header's own width (a container query at 45rem), not the window, so it works in a narrow frame too.
  • Mark the current page with aria-current="page", never a class.
  • The sheet opens across the top of the window. On this preview page it spans the whole window even from the 375px frame.
