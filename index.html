@brignano/design

Design system

Competence and calm.

The foundation under brignano.io and every tool beside it. Near-monochrome, with colour used so sparingly that when it appears, you look at it. Every page here renders straight from tokens.css, in light and dark side by side.

npm install @brignano/design
Source npm Decisions

Colour

Three layers, so no colour does two jobs.

Identity

Inks a graphic only: a product's glyph, the monogram, a hero rule. Never a control.

--mark

Interactive

One hue for everything you can act on, in every state.

--i

State

Settled, wants you, gone wrong. Always with an icon or a word.

--success · --attention · --danger
