Why use it

The boring decisions, already made.

Colour that means something

One colour means "you can tap this". Amber means "this needs you". Red means "something went wrong", always with a word, so nobody has to guess.

Dark mode and phones, done

Every part works in light and dark, and every button is big enough for a thumb. You don't design anything twice.

Whole pages, not just buttons

Start from a finished 404, settings page, changelog, article or email instead of an empty file.

Get started

Up and running in three steps.

  1. Install it
    npm install @brignano/design
  2. Add it to your styles
    @import '@brignano/design/tokens.css';
@import '@brignano/design/components.css';
  3. Use a part
    <button class="btn btn-primary">
  Save
</button>
