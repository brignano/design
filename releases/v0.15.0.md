A new logo: "ab" in lowercase with a block cursor after it, replacing the `A|B` mark.

## Upgrading: what changes on your site

- **The logo changes shape.** `logo/paths.mjs` keeps `MARK` and `TILE` and the `letters`/`bar` keys (`bar` is now the cursor), so a site that inlines the logo picks it up with no code change. `MARK` is now 51.6 × 24 (was 41.33 × 24); code that sizes by height and reads `MARK.width` keeps working.
- **New icons.** `logo/tile.svg`, `logo/tile-180.png`, `logo/tile-512.png`, `favicon.svg` and `favicon.ico` carry the new mark. A site that copied the tile into its own `public/` should copy it again.
- Same colour rule: the letters are ink, only the cursor is amber.

## Also

- `scripts/logo.py` draws the logo from Geist 800, so it can be redrawn exactly.
- ADR-0021 and DESIGN.md §5 "The logo". The `.stamp` text (`A|B` in footers) is unchanged for now.
