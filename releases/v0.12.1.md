The decision log is now one file per decision. No tokens, classes or files you style with changed.

## Upgrading: what changes on your site

Nothing, unless something links to `DECISIONS.md` inside the package. That file is gone: the package ships `decisions/` instead, with an index at `decisions/README.md`.

## Decisions, one per file

- **`decisions/NNNN-slug.md`**: each of the 18 ADRs that were in `DECISIONS.md`, with its number, date and wording unchanged (#173).
- **`decisions/README.md`**: the index, with every ADR and its date.

## For contributors

- `npm run check` now pairs a text colour with the background its parent rule sets, so an ink nested on a wash is held to 4.5:1 too (#172).
- AGENTS.md has a checklist for adding or changing a component: 44px on coarse pointers, a marketing-tier demo, specificity against earlier rules, and demos outside the preview chrome (#170).
