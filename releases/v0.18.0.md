A command that checks an app against the system, and a styled select menu so no site shows a browser dropdown.

## Upgrading: what changes on your site

- **New `design audit` command.** Run `npx @brignano/design audit [paths]` in an app. It lists, with `file:line`, every colour, font, radius, shadow or spacing value that isn't a token, and every `var(--…)` the package doesn't define, and exits 1. Spacing is a warning for now (`--spacing=error` makes it an error). To allow one exception, add `design-exception: brignano/design#N` on or above the line; it passes while that issue is open. Nothing changes until you run it.
- **New select menu (`.select-menu`).** It replaces the native `<select>`, whose open list is the operating system's. Use a `.select-menu` button with a `.popover` holding a `.menu` of radio items (see `previews/select-menu.html`). A native `<select>` inside `.field` still renders, but only as the no-script fallback.
- **New `.link-external` and `.visually-hidden`.** Put `link-external` on a link that opens in a new tab to draw the external-link icon, with a `.visually-hidden` span saying "(opens in a new tab)". Existing links don't change.

## Also

- The docs site is a docs-style home with a sidebar, search and a product picker, and it compares each part across products. The site-wide theme is gone.
- CI renders every gallery page and fails on errors, sideways scroll or squashed blocks, and runs the fleet ui-check.
